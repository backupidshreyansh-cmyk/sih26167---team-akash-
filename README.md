# SatQuery AI

## Evidence-Driven Satellite Intelligence

SatQuery AI is an interactive Vision-Language Assistant for multimodal remote-sensing image analysis through natural-language queries.

Built for **Smart India Hackathon 2026 – Problem Statement 26167**.

## The Problem

Satellite imagery contains valuable information across optical, multispectral, SAR, geographic, and temporal observations. However, answering a natural-language question often requires more than simply asking an AI model to describe an image.

A model may produce a convincing answer even when the available imagery does not contain enough evidence to support the claim.

## Our Solution

SatQuery AI converts a natural-language question into an evidence-driven analysis process.

```text
Question
   ↓
Understand the requirement
   ↓
Identify required evidence
   ↓
Analyse available imagery
   ↓
Measure and validate evidence
   ↓
Check limitations and conflicts
   ↓
Generate the final answer
