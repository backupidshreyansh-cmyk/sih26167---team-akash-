## 2. Evidence Sufficiency States
The application does not equate "Model Confidence" with "Verified Truth". Every claim is labeled with one of the following sufficiency states:
- `VERIFIED`: Deterministic confirmation.
- `HIGH / SUPPORTED`: Strong multi-modal agreement.
- `MEDIUM`: Model inference without contradiction.
- `LOW / INCONCLUSIVE`: Weak evidence or missing modalities.
- `CONFLICTING EVIDENCE`: Optical and SAR actively disagree.
- `INSUFFICIENT EVIDENCE`: Input images lack the information required to answer the query.

## 3. Security
- **No Direct LLM Execution**: The VLM cannot run terminal commands. All tool selection is mapped via a strict TypeScript registry.
- **Input Validation**: Backend strictly rejects files >50MB.
